# Edgar Medina — Senior AI Engineer | Generative AI & Computer Vision

10+ years building production ML systems — from peer-reviewed research (**WACV 2024, VISAPP, WSCG**) to enterprise-scale deployments (General Electric, and fast-moving SaaS/consulting teams). I work across two areas:

- **Generative AI** — RAG & GraphRAG systems, LLM-based extraction/evaluation pipelines, agentic workflows (LangGraph), local LLM fine-tuning, Model Context Protocol (MCP) integrations.
- **Computer Vision** — 3D reconstruction (Gaussian Splatting), scene understanding, multi-modal vision-language pipelines, motion forecasting.

**Selected impact:**
- Reduced production service costs by 50%+ via model profiling and cost-analysis pipelines
- Improved multi-label classification F1 from 55% → 70% by redesigning the training/data pipeline
- Built a knowledge-graph + LLM entity-linking pipeline running over 38M+ production records
- Published at WACV 2024, VISAPP (oral), WSCG — human motion forecasting & adversarial robustness
